Taruh file musik di folder ini, lalu sesuaikan nama file pada
config.js bagian "music".

Contoh: lagu favorit kalian, atau instrumental bebas royalti.

Catatan:
- Format MP3 atau M4A/AAC sama-sama didukung browser modern.
- Ukuran disarankan di bawah 8 MB supaya cepat dibuka di HP.
- Lagu otomatis diputar setelah lilin ditiup.
- Kalau file tidak ada, website tetap berjalan normal;
  hanya tombol musiknya yang nonaktif.
